## Overview

This repository contains practice materials for the System Analysis and Design course at HUIT.

## Main Topics

- System analysis
- Use case modeling
- Activity diagrams
- Database design
- Documentation practice
- Course exercises

## Repository Purpose

This repo is used to organize analysis diagrams, design documents, and practice files for coursework.

## Learning Outcomes

- Analyze software system flows
- Create clear diagrams and documentation
- Practice turning user needs into system models
- Build a stronger foundation for UI/UX and software design work
